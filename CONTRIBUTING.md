# Submission Instructions

Do not delete this file — it is part of the required template structure.

1. Fill in `submission.yaml` completely — every `# REQUIRED` field must be
   non-empty or the automated validator will fail.
2. Replace every `[placeholder]` in `README.md` with real content. Search
   the file for `[` before pushing to catch anything you missed.
3. Write real content (not template text) in every file under `docs/`.
4. Put all source code under `src/`. Keep `src/.env.example` up to date
   with every environment variable your code needs.
5. Record a 3–5 minute demo video showing the app actually running, and put
   the real URL in `demo/demo-video-link.txt`. Add at least 3 screenshots to
   `demo/screenshots/`.
6. Add your slide deck to `presentation/` as `slides.pdf` (preferred) or
   `slides.pptx`.
7. Push your changes and confirm the **Validate Submission** GitHub Action
   is green under the repo's Actions tab.
8. Set the repository visibility to **Public**.
9. Submit your repo URL via the official entry form before the deadline.

See the full submission guide shared by the organisers for detailed
per-file requirements and the judging rubric.
